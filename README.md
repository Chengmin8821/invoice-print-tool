# 发票拼版打印工具

把几十张电子发票（PDF / OFD / JPG / PNG）一键排成 A4 打印页——宽票两张一页、小票三张一页、长票独占一页，全程本地离线。

## 下载

前往 [Releases](../../releases) 页面下载最新版本：

- `print-invoices-v1.0.zip`（约 44 MB）
- 解压后双击 `发票拼版打印工具_v1.0.exe` 即可运行，**无需安装 Python 或任何运行库**

## 功能

| 功能 | 说明 |
| --- | --- |
| 全格式混排 | PDF、OFD（本地转换）、JPG、PNG 混在一个文件夹里一起处理 |
| 智能裁边 | 自动裁掉 A4 整页四周的白边与页脚，保留顶部抬头和二维码 |
| 按票配页 | 按每张票的实际尺寸决定：宽票 2 张/页、小票 3 张/页、超长票 1 张/页 |
| 不变形不放大 | 只等比缩小，绝不拉伸，小票按原尺寸居中 |
| 免安装单文件 | 一个 exe，双击即用 |
| 出错不闪退 | 文件被占用自动换名保存，异常时窗口停住并写明原因 |

## 使用方法

1. 把所有发票放进同一个文件夹（不要有子文件夹）；
2. 把文件夹拖到程序图标上松手，或双击程序后把路径拖进窗口按回车；
3. 打印生成的 `发票文件夹\打印版\print_ready.pdf`，纸张选 A4、缩放选「实际大小 100%」。

## 隐私

纯本地离线程序：**不联网、不上传、不存储**任何发票内容，OFD 转换也在本机完成。

## 系统要求

Windows 10 / 11（64 位）。首次运行如遇「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可。

## 说明

本工具仅做版面排版，不涉及发票真伪查验或税务接口。
